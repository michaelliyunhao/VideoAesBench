# VideoAesBench

## Overview
Codebase for "VideoAesBench: Benchmarking the Video Aesthetics Perception Capabilities of Large Multimodal Models"

The paper is accepted in ACMMM 2026.

## Dataset Release
### Download
The dataset can be downloaded from [Hugging Face](https://huggingface.co/datasets/chris-123/VideoAesBench).

Video Data: final_video_released.zip

Questions and answers: videoaesbench_qa.jsonl
